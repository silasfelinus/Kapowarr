Import an existing organized library to add volumes to Kapowarr

A few notes:

  • Review Scan is the familiar workflow: scan a batch, check Kapowarr's ComicVine matches, then confirm the import yourself.
  • Continuous Auto-Import checks all root folders in the background, one folder at a time. Strong ComicVine winners import automatically; tied, weak, or missing matches are held untouched for manual review.
  • While Continuous Auto-Import is running, you can open its accumulated review holds without stopping it, or request a safe stop after the current folder boundary.
  • Continuous mode deliberately spaces ComicVine search starts to stay below the documented request ceiling. You can leave this page while the server-side task keeps working.
  • Manual review batches can still reach ComicVine's rate limit. Kapowarr reports that condition instead of silently turning it into a missing match.
  • Files are not allowed to be directly in the root folder. They have to be in a sub-folder.
  • If each issue has a separate sub-folder, enable 'Apply limit to parent folder' for Review Scan so that the limit is correctly applied.

*Input has to be a folder (pattern) and all matches have to be a root folder or a sub-folder of one

Continuous Auto-Import always scans all configured root folders, matches English volumes, and keeps existing filenames/folders. The controls above apply to Review Scan.
