Download Location

The folder that direct downloads temporarily get downloaded to before being moved to the correct location

A folder that Kapowarr checks every 15 minutes for comics you acquired elsewhere. Files that have finished writing and match a volume already in your library are moved in, renamed and converted like a normal download. Anything unmatched is left untouched. Leave empty to disable. It cannot overlap a root folder or the temporary download folder.

Removes any "ghost" files in the direct download temporary folder (handy if the application crashed while downloading, leading to half-downloaded files in the folder).

Preferred acquisition protocol when otherwise-equivalent matches are available: Direct (including GetComics), Torrent, or Usenet.

Search every source asks all of them at once and uses Source Priority to pick between the results. It finds the most, and it spends every source's quota on every search.

Stop at the first source with a match works down Source Priority and stops as soon as one actually has the issue, so a source further down is never asked when a preferred one already had it. Choose this when your sources are not equally cheap — an unmetered Usenet account above tightly rationed public torrent indexers, for instance. It can miss a better release that a lower-priority source had.

Minimum seconds between two requests to the same torrent indexer. The default is 1. Set to 0 for no delay.

Note that one search is several requests: it tries up to four phrasings of the title, stopping at the first that returns anything, and asks every torrent indexer each time. A fruitless search therefore costs roughly four times this delay — 5 seconds here is about 15 seconds per search, and 30 is about 90. Pick it against how long a sweep of your whole library may take, not just against the indexer’s patience.

The same, for Usenet indexers. The default is 0, since most allow far more queries than a search will ever use.
